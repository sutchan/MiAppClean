交互标准

统一交互模式与反馈语言，确保用户在任何页面获得一致、可预期的体验。覆盖：交互模式、反馈、错误处理、空状态。

1. 交互模式 Patterns

选择模式

互斥单选用分段控件；多选用复选框

确认模式

确认卸载？

卸载后应用将被移除，需恢复出厂才能装回。

破坏性操作必须二次确认

渐进披露

高级选项

默认隐藏次要设置，点击展开。降低首屏认知负荷。

复杂表单用折叠面板分组

2. 反馈 Feedback

即时反馈

按钮态变化（hover/active/loading）即时可见

轻提示 Toast

非阻断提示，2s 自动消失

状态徽章

已生成 已选 12 部分风险

持续态用徽章而非 Toast

3. 错误处理 Error

字段级错误

包名格式无效：缺少末尾标识，请检查

错误就近展示，说明原因 + 建议

阻断错误（Dialog）

未检测到设备

请确认已开启 USB 调试并通过 adb devices 识别到设备。

阻断性错误用对话框，提供下一步动作

命令错误注释

# 跳过：com.android.settings 为核心组件，禁止精简
# 警告：com.miui.audioeffect 精简后可能影响音效

命令生成时失败项以注释说明，不中断

4. 空状态 Empty

无勾选项

📋

尚未选择任何应用

勾选上方应用或粘贴自定义包名后，将在此生成 adb 命令。

空状态需说明「是什么、为什么、怎么做」，并提供主操作

无搜索结果

未找到匹配的包名，请调整关键词或清空筛选。
