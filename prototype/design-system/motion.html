动效 Motion

动效服务于理解，而非装饰。所有过渡统一缓动曲线与时长令牌，时长克制（120–320ms），尊重 reduce-motion。

缓动曲线与时长

令牌值用途
--ease-standardcubic-bezier(.2,0,0,1)常规进出（hover、展开）
--ease-emphasizedcubic-bezier(.3,0,0,1)重要状态（选中、提交）
--ease-deceleratecubic-bezier(0,0,0,1)进入（滑入、淡入）
--dur-fast120ms即时反馈（按钮、开关）
--dur-base200ms常规过渡（颜色、位移）
--dur-slow320ms较大位移（抽屉、弹层）

无障碍约束

检测到 prefers-reduced-motion: reduce 时，所有非必要动效停用，仅保留 opacity 即时切换，避免前庭功能障碍用户不适。
@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; transition: none !important; }
}
