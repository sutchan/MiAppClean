设计系统

定义 MiAppClean 的视觉语言与基础规则。所有界面代码与原型统一引用 tokens.css 中的设计令牌，确保跨页面、跨设备的一致体验。

设计原则

1. 极简克制

以留白替代分割线，以层次替代装饰。界面只保留完成任务所必需的元素，避免视觉噪音。

2. 高对比可读

文本与背景对比度满足 WCAG AA（正文 ≥ 4.5:1）。主色仅在关键操作与强调处使用，不滥用。

3. 移动优先

布局以窄屏为基准设计，向宽屏渐进增强。触控目标 ≥ 44×44px，保证手指可操作。

4. 一致反馈

相同的操作在任何位置都有相同的外观与反馈。状态变化通过动效传达，而非突兀跳变。

令牌层级

层级作用示例
原始值 Primitives不可变的色值/尺寸常量#ff6900
语义令牌 Semantic带意图的别名，组件引用此层--color-primary
组件令牌 Component组件内部专用微调（可选）--btn-primary-bg
组件只应使用语义令牌；修改品牌色只需变更语义令牌映射，无需改动组件。

快速开始

在任意原型或界面页面中引入令牌与共享样式：

<link rel="stylesheet" href="design-system/tokens.css" />
<link rel="stylesheet" href="design-system/doc.css" />

应用原型（app/）使用独立的 app.css，但同样基于上述令牌变量。

主题切换（深浅色）

设计令牌内置浅色（默认 :root）与深色两套值。原型右上方提供 ☀ 浅色 / 🌙 深色 / 🖥 跟随 三态切换控件，由 theme.js 驱动：

  • 浅色 / 深色：显式写入 html[data-theme]，强制覆盖系统偏好，选择持久化于 localStorage。
  • 跟随：移除 data-theme，由 @media (prefers-color-scheme) 自动匹配系统；切换系统时实时响应。
  • 首屏在 <head> 同步应用已存主题，避免深浅闪烁。
新增页面只需在 <head> 引入 theme.js 即可获得切换能力，无需额外样式。

无障碍基线 Accessibility

所有页面与组件遵循 WCAG 2.1 AA，最低满足以下基线：

  • 键盘可达：所有可交互元素均可 Tab 聚焦；分段控件用原生 radio + role="radiogroup"，对话框用 role="dialog" aria-modal。
  • 可见焦点：统一提供 :focus-visible 焦点环（2px 主色描边，偏移 2px），不依赖鼠标悬停。
  • 对比度：正文文本对比度 ≥ 4.5:1，大号文本与图标 ≥ 3:1；深浅色均经令牌约束，不写死低对比色值。
  • 语义标签：按钮用 <button>（非 div），图标按钮补 aria-label；表单控件绑定 label for，错误态加 aria-invalid。
  • 触控目标：按钮最小可点区 40×40px，图标类 44×44px，避免误触。
  • 动效偏好：尊重 prefers-reduced-motion，时长级动效在该模式下降级为瞬时。
令牌中的 --duration-* / --ease-* 已为动效唯一来源；若需支持减弱动效，可在 tokens.css 追加 @media (prefers-reduced-motion: reduce) 覆盖。
