复合组件 Composite

由基础组件组合而成，承载局部交互：折叠面板、对话框、抽屉、Toast、命令输出块。

Disclosure 折叠面板

广告模块（5）
com.android.adservices.api安全
com.miui.analytics安全

用于按类别分组包名，默认展开

Dialog 对话框

确认执行精简？

将对所选设备执行禁用操作，被禁用的应用可随时通过 pm enable 恢复。

关键操作前确认；点击遮罩或 Esc 关闭

Drawer 抽屉

操作详情

抽屉从右侧滑入，承载较多内容（如完整命令预览、设置项）。点击遮罩关闭。

移动端优先的二级页面容器

Toast 提示

操作结果轻提示，2s 自动消失

Command Output 命令输出块

adb shell pm disable-user --user 0 com.miui.analytics
adb shell pm disable-user --user 0 com.xiaomi.gamecenter  # 谨慎：可能影响相关功能
# 已跳过危险组件（严禁精简，可能变砖）：com.android.settings
