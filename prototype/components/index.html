组件库

分层组织组件：基础（原子）→ 复合（组合交互）→ 业务（领域封装）。所有组件基于设计令牌，可在原型与最终界面中直接复用。

层级概览

层级职责示例
基础 Base原子元素，单一职责，无业务语义Button / Input / Badge / Checkbox / Segmented
复合 Composite基础组合，承载局部交互模式Disclosure / Dialog / Drawer / Toast / CommandOutput
业务 Business领域封装，含真实数据语义DeviceSelector / ModeSwitch / RiskTag / PkgItem / CategoryGroup

设备选择、模式切换、风险标签、包名行、类别分组

使用约定

  • 组件只消费语义令牌，不写死色值/尺寸。
  • 交互元素最小触控区 40×40px（按钮）/ 44×44px（图标）。
  • 所有可聚焦元素提供 :focus-visible 可见焦点环。
  • 业务组件状态由数据驱动（risk、checked），与渲染解耦。
