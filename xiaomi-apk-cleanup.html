风险提示

  • 操作前请备份设备数据，并对设备做一次完整备份。
  • 优先使用「禁用」模式，应用停止运行但保留在系统，可一键 pm enable 恢复。
  • 包名含 system / framework / telephony / settings 的核心组件切勿精简，可能变砖。
  • 不同机型/系统版本包名不同，执行前请先用 adb shell pm list packages <包名> 核对。
  • 电视盒精简后若丢失桌面（Launcher），用 pm enable <包名> 重新启用。
