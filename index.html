小米内置应用精简清单说明

MiAppClean 收录小米手机（MIUI / HyperOS）、平板、电视盒（MiBox / 乐视 X600 等）的内置应用包名，按设备与风险分级整理，可一键生成 adb shell pm disable-user 或 pm uninstall --user 0 命令。

  • 安全（safe）：广告模块、统计、部分可卸载的预装 App，可放心精简。
  • 谨慎（caution）：输入法、音效、定位等，精简后可能影响部分功能，按需保留。
  • 危险（danger）：系统设置、桌面 Launcher、系统界面等核心组件，严禁精简，工具会自动拦截。

完整包名清单与逐机型明细见文档： 各机型内置 App 包名清单、 通用精简命令模板。

⚠️
  • 操作前请备份设备数据；优先使用「禁用」模式（可 pm enable 恢复）。
  • 包名含 system / framework / settings 的核心组件切勿精简，可能变砖。
  • 执行前先用 adb shell pm list packages <包名> 核对包名是否真实存在。
