## 任务三：修复 app/ 功能缺陷（承接 grill-me 深挖，lint 0 错误）

基于磁盘真实状态修复 app/ 线上工具的真实功能缺陷（v1.15.3 只清了死代码，功能缺陷仍留待修复）。**关键教训：`read_file` 曾返回 IDE 缓存（含已删除的死代码），`search_content`/`git diff`/`git status` 读真实磁盘。涉及"确认文件当前状态"必须用 search_content 或 git 命令，勿信 read_file 缓存。**

修复项：
1. **卸载模式弹窗逻辑**（`app.ui.js` bindSegment + `app.ui.handlers.js` confirmUninstallWarn）：原代码注释称"确认前临时回退禁用模式"但实际未回退、`toggleUninstallWarn()` 重复调用、`generate()` 无条件立即执行。现改为：切卸载 → 弹窗确认 → 确认保持卸载并刷新；取消则 `setMode` 回退禁用 + 置回 radio + 刷新。`confirmUninstallWarn` 增加 `onCancel` 第二参数、Esc 关闭、初始焦点落「取消」（安全默认）。**注意变量遮蔽坑**：内部取消处理函数命名 `onCancel` 会遮蔽参数 `onCancel`，已改名 `onCancelClick`。
2. **主题系统双依赖**（`app/index.html`）：移除 `<script src="/prototype/theme.js">`（app 已自带 settings.js 主题逻辑，theme.js 会注入多余 FAB），改为内联首屏同步脚本（localStorage `miac-theme` 读取，避免深色闪烁），运行时仍由 settings.js 接管。
3. **焦点管理**（`settings.js` bindDrawer + `handlers.js` confirmUninstallWarn）：设置抽屉补初始焦点（关闭按钮）、关闭后归还焦点（记录 `document.activeElement`）、Tab 焦点陷阱（shift+Tab 循环）、遮罩点击限定 `e.target===overlay`。卸载确认弹窗补 Tab 循环 + 关闭归还焦点。
4. **reduced-motion 统一**（`app.base.css`）：移除重复的 `@media(prefers-reduced-motion){*{animation:none}}` 块，统一由 tokens.css 的更克制降级块处理。
